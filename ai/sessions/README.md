## 规则

- 文件名 `NNN_<slug>.md`：**纯 ASCII**、小写下划线、`slug` 用英文短名；**编号连续、不复用**。
- **一段会话只记一件事** —— 粒度过粗就没法提炼技能包。
- **「原文位置」字段必须填**，且必须指向 `ai/raw/` 的真实分片（★ **2026-10-19 起 `ai/raw/` 已落盘**，格式 `YYYY-MM-DD_<短ID>.md`，见 [`../raw/README.md`](../raw/README.md)）；
  **不得编一个不存在的文件名**。引用时**只写令牌 `VERIFY_RAW_OK` + 重跑命令 + 核对日期，不写条数**（条数是时点值，会随主会话增长而漂移）。
- **自我纠错轨迹必须带硬证据**：工具链报告 / 仿真波形 / 板级实测 / 官方文档**具体章节号** / 仓库内原文。
  ⛔ 禁止「感觉不对」「经验上」「一般来说」「我记得」—— 拿不出证据的条目**不要写进纠错轨迹**。
- **边做边记**：纠错上下文几个月后无法还原，事后补记等于伪造。
- 没有纠错的会话也可以记，但**价值低于**有纠错的会话。

## 怎么用

```powershell
# 开一条新记录（编号取 INDEX.md 里的 max+1）
Copy-Item D:\zynq-yolo\ai\sessions\_TEMPLATE.md D:\zynq-yolo\ai\sessions\002_<slug>.md
# 写完 → 在 INDEX.md 追加一行（顺序不可反）→ 问一句「有什么换个题目也能用的？」
```

> 沉淀去向是**仓库根的** [`../../skill/`](../../skill/)，不在本目录下。
