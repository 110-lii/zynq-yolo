## ★ 自我纠错轨迹

> **本层最值钱的部分，也是唯一无法事后伪造的部分**（指南 3.3.5.3 明确要求「自我纠错轨迹」）。
> 一条合格的纠错必须回答四件事：**错在哪 → 怎么发现 → 怎么改 → 判据**。**证据栏不得为空。**

| 项目 | 内容 |
|---|---|
| **错在哪**（原始判断） | <AI / 人 当时以为是什么；**写当时的原话或原做法**，不要用现在的认识重述> |
| **怎么发现**（触发条件） | <什么事件暴露了它：报错、用户纠正、复算、交叉验证> |
| **证据** | <**必须可核验**：报告文件名 + 具体行 / 波形或 tb 输出 / 板级实测读数 / 官方文档章节号 / 仓库内原文位置> |
| **怎么改**（修正动作） | <改提示词？补上下文？查文档？换方案？改完把哪几处同步了？> |
| **判据**（怎么确认改对了） | <**可重跑的判据**：命令 / 断言 / 数字对比。写不出判据 = 没验证> |
| **根因归纳** | <为什么会犯这个错 —— 这条决定它能否沉淀成技能包> |

### 证据的可接受来源

| 类别 | 示例 |
|---|---|
| 工具链报告 | Vivado `*_utilization_report.rpt`、`*_timing_summary_routed.rpt`（**指标名 + 数值**） |
| 仿真 | testbench 输出、断言失败信息、波形信号名与取值 |
| 板级实测 | ILA 抓取序列、串口日志原文、示波器 / 逻辑分析仪读数、实拍图 |
| 官方文档 | **UG585**（Zynq-7000 TRM）· **UG901**（Vivado 综合）· **UG904**（实现）· **UG949**（设计方法学）· **UG1399**（VHDL / 语言支持）等的**具体章节号**，不是「某文档里说」 |
| 仓库内原文 | `ai/raw/` 的分片与轮次号 · `../.research/guide_amd_2026.txt` 的行号 · `../../docs/repo_spec.md` 的节号 |

> ⛔ **禁止**：「感觉不对」「经验上」「一般来说」「我记得」。
> **拿不出证据的条目不要写进本表** —— 写进去反而暴露材料是编的。
