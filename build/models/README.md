## 内容

| 路径 | 说明 |
|---|---|
| `person_v8n25.*` | 球员检测 ncnn 模型（**当前在板默认**，320 输入） |
| `ball_roi.npz` | 球 ROI 分类器权重 |
| `person_w05_320.*` / `_480.*` / `_640.*` | **2026-11-02 微调权重按输入尺寸分别导出**（D043），默认未启用。★ 一个 ncnn 模型只能跑它导出时的边长 —— 换尺寸必须重新导出，不能只改调用参数；文件名里的数字就是它的边长 |

## 规则

- 只放「板上跑得起来」的最小集；训练中间产物放 `data/`
- **模型名带输入尺寸**（`person_<name>_<S>`）：静态图导出的尺寸写死在 param 里，名字不带尺寸最容易拿错
- `.bin` 默认被 `.gitignore` 忽略；`person_v8n25.bin` 是强制入库的在板件，
  `person_w05_*` 三档待板端耗时实测选定后再决定是否入库（现状见 Session 029）

## 怎么用

- `py tools/make_submission.py` 会显式带入本目录必需件
