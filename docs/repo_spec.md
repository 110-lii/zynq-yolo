## 1. 命名规则（强制）

1. **目录名与文件名：纯 ASCII**，只用 `a-z 0-9 _ -` 与 `.`。**禁止中文、空格、括号、全角字符**。
2. **文件正文可以用中文**（指南明确允许）。
3. 目录名一律**小写**；`snake_case` 用下划线，不用驼峰。
4. 每个目录都必须有一份 `README.md`，首行说明「本目录装什么 / 谁产生」。
5. 版本/日期后缀用 `_YYYYMMDD`，例如 `reports_20261019`。
6. 禁止在仓库里出现 `build*.log`、`vivado*.log|jou`、`.Xil/`、`*.dcp`、`__pycache__/`、`.venv/`（见 `.gitignore`）。

## 4. 「真源 vs 产物」规则（承旧项目已验证纪律）

> **能由仓库内脚本一条命令重建的，就是产物；产物不进 git 或只保留基线。**

| 类型 | 位置 | 能改吗 | 进 git |
|---|---|---|---|
| 设计真源 | `src/` | ✅ 只在这里改设计 | ✅ |
| 构建真源 | `build/scripts/` | ✅ | ✅ |
| 仿真真源 | `sim/tb`、`sim/scripts` | ✅ | ✅ |
| 上板真源 | `board/scripts`、`src/ps` | ✅ | ✅ |
| 文档真源 | 所有 `.md` | ✅ | ✅ |
| **产物** | `build/reports/*`、`board/overlay/*.bit`、`board/logs/*` | ❌ 会被重建覆盖 | 只留有价值的基线 |

**判据**：**不能由脚本重建的（串口日志、肉眼观察、实拍截图、实测数字）必须落盘**；
能重建的（`.bit` / `.rpt` / `.dcp` / `.log`）由 `.gitignore` 排除。

### 4.1 空目录占位：`.gitkeep`（**易被误删，必读**）

> **git 不跟踪空目录。** 本仓库骨架有 **31 个当前为空的预留目录**（`src/rtl/*`、`sim/{tb,vectors,scripts}`、
> `build/reports/{synth,impl,timing,resource,drc}`、`board/{overlay,scripts,logs,images}`、
> `data/{models,calib,samples,golden,results}`、`report/{figures,llm_logs}` 等），
> 每个都放了空文件 `.gitkeep` 占位。**没有它，clone 后这 31 个目录全部消失，骨架缩水。**

硬规则：
1. `.gitkeep` **不是垃圾**，删了就等于删目录。**不要删除、不要往里面写内容**。
2. **不要把它加进 `.gitignore`** —— 恰恰相反，`.gitignore` 里必须为它留 `!` 白名单
   （`build/reports/*`、`board/logs/*` 两处已做，见根 `.gitignore` 对应块）。
3. **改 `.gitignore` 时注意 git 语义**：父目录一旦被排除，其下内容**无法**用 `!` 重新包含。
   所以白名单顺序必须是「先放回子目录本身 → 再放回 `.gitkeep` / `baseline*`」。
   改完必须用临时仓库实测 `git ls-files "*gitkeep"` 的条数 = 磁盘上的条数；
   **磁盘上存在但 `git ls-files` 里没有的，就是被吃掉的白名单**（本轮实测曾吃掉 6 个）。
4. 目录将来有真文件后，`.gitkeep` 可删（非强制）。
